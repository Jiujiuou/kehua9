# 可话动态查看器

## 📖 项目背景

这个项目源自一个叫「可话」的 APP，这个 APP 主打的是分享社交，分享内容后，可以共鸣到其他用户的内容。

现在这个 APP 倒闭了，倒闭后 APP 提供了链接支持用户导出这么多年的数据。数据格式是 **txt 文件 + 图片文件夹**，预览起来非常不便：

### 原始数据格式示例

```
2021年10月11日 15:13:59
瞎拍
[图片：20211011-151359-1.jpeg]


2021年10月13日 16:07:42
瞎拍
[图片：20211013-160742-1.jpeg]


2021年10月14日 12:47:04
当情绪在舒缓的音乐中荡漾着趋向于平缓的时候，先前努力的念头也随之消散，只想着这样的场景可以像路灯下远去的人影一般再拉长一些。
```

每条记录都是以**时间开头**，然后是**文字描述**，最后是**图片链接**（图片链接不一定存在）。

### 痛点

由于 txt 中的文字和图片不在同一个文件夹，预览起来非常麻烦。看完文字如果想看图片还得翻开其他文件夹去查询。

**因此我做了这个网站，来解决这个痛点。**

## ✨ 核心功能

### 📂 数据导入与解析
- **智能解析**：自动解析可话导出的 txt 文本和图片/视频文件
- **批量导入**：支持选择整个文件夹，一次性导入所有年份的动态数据
- **多媒体支持**：
  - 图片格式：jpg, png, gif, webp
  - 视频格式：mp4, mov
- **路径兼容**：支持多种文件夹结构（`我的动态/2021年/...`、`2021年/...` 等）

### 🔍 动态浏览与搜索
- **时间轴展示**：按时间顺序展示所有动态
- **目录导航**：左侧按年月日分组的目录树，快速定位任意日期
- **全文搜索**：支持关键词搜索动态内容
- **类型筛选**：按内容类型筛选（全部/纯文字/图片/视频）
- **排序方式**：支持正序/倒序切换

### 🎨 个性化样式定制
- **文字样式**
  - 字体大小：12px - 24px
  - 字体粗细：300 - 700
  - 字体族：系统字体/思源黑体/思源宋体等多种选择
  - 行高：1.0 - 2.0
- **排版控制**
  - 段落首行缩进：开启/关闭
  - 段落后空行：是/否
  - 内容间距：6px - 40px
- **视觉效果**
  - 图片间距：0px - 20px
  - 预览边距：10px - 40px
  - 动态圆角：4px - 20px
- **主题切换**：支持亮色/暗色主题

### 🖼️ 媒体预览
- **图片预览**：点击图片全屏预览，支持左右切换
- **视频播放**：内嵌视频播放器
- **卡片预览**：点击动态查看详情，支持上下翻页

### ✏️ 动态管理
- **添加动态**：手动添加新的动态内容
- **删除动态**：删除不需要的动态（同时删除文件）
- **拖拽排序**：通过拖拽调整动态显示顺序

### 💾 数据持久化
- **配置保存**：所有样式配置自动保存到浏览器 localStorage
- **本地操作**：支持使用 File System Access API 直接修改本地文件

## 🚀 快速开始

### 环境要求
- Node.js >= 16.x
- npm >= 8.x
- 现代浏览器（Chrome 86+, Edge 86+）

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 `http://localhost:3000` 即可开始使用。

### 生产构建

```bash
npm run build
```

构建完成后会：
1. 在 `dist/` 目录生成 `template.html`（单文件应用）
2. 自动复制到根目录 `index.html`
3. 复制到 `dist/index.html`

构建后的 HTML 文件可直接在浏览器中打开使用，无需服务器。

## 🔧 核心功能实现

### 1. 数据解析（`parseData.js`）

支持解析可话导出的数据格式：

```
文件夹结构：
我的动态/
  └── 2021年/
      ├── 2021年-动态内容.txt
      └── 2021年-图片/
          ├── 20211011-151359-1.jpeg
          └── ...
```

解析逻辑：
1. 读取 txt 文件，按时间戳分割动态
2. 提取文本内容和图片/视频引用
3. 匹配图片/视频文件到对应动态
4. 生成结构化数据数组

### 2. 本地文件操作（`writeData.js`）

使用 **File System Access API** 实现：
- 添加新动态：创建新文件夹和 content.txt
- 删除动态：同步删除本地文件和文件夹
- 修改动态：更新 txt 文件内容

### 3. 配置持久化（`storage.js`）

所有用户配置保存到 localStorage：
- 排序方式、筛选条件
- 字体、排版、视觉效果参数
- 主题偏好

### 4. 目录树导航（`Catalog`）

- 自动生成年/月/日三级目录
- 支持展开/折叠
- 点击日期自动滚动到对应位置
- 根据滚动位置高亮当前日期

### 5. 主题切换

通过 `data-theme` 属性控制：

```javascript
document.documentElement.setAttribute('data-theme', 'dark');
```

组件通过 CSS 变量响应主题变化。

## 🎯 使用说明

### 导入数据

1. 点击主预览区的 **「打开文件夹」** 按钮
2. 选择可话导出数据的根目录（包含 `我的动态` 或直接是年份文件夹）
3. 浏览器会自动解析所有年份的动态数据
4. 解析完成后即可在界面中浏览

### 浏览动态

- **滚动浏览**：在主预览区滚动查看所有动态
- **目录跳转**：点击左侧目录树快速定位到某一天
- **搜索内容**：在顶部搜索框输入关键词
- **筛选类型**：在右侧控制面板选择内容类型

### 查看媒体

- **图片**：点击图片全屏查看，支持左右箭头/滑动切换
- **视频**：点击播放按钮观看视频
- **详情**：点击动态卡片查看完整内容

### 自定义样式

在右侧控制面板调整：
- 拖动滑块调整间距、字号等数值参数
- 点击开关切换布尔选项（缩进、空行等）
- 下拉选择字体族

所有配置实时生效并自动保存。

### 管理动态

- **添加**：点击 **「添加动态」** 按钮（需先打开文件夹）
- **删除**：点击动态卡片上的删除按钮，确认后删除
